# Appendix tables: what produces what

The camera-ready appendix `\input{}`s 13 tables from
`COLM_camera_ready/tables/`. Each is generated by a module under
`src/anchorbench/analysis/`, from results under `results/rebuttal/`, which
were produced by a launcher in `scripts/rebuttal/`.

Regenerate all 13:

```bash
anchorbench tables --appendix
```

That needs `results/rebuttal/` — it is published as [downloadable tarballs](https://drive.google.com/drive/folders/1Befi102mkvXQomB1zwCPS_m0_4OlKH2M?usp=sharing)
rather than committed, since it is 402 MB. The ~1 MB of derived `.tex`, `.csv`, `.json`
and `.md` inside it *is* committed, so the tables themselves are in git even
when the generations are not.

Verified: running `--appendix` reproduces all 13 committed tables
byte-for-byte (`tests/test_golden_artifacts.py`).

`analysis.cohens_d` also runs under `--appendix`. It produces
`rebuttal/cohens_d/cohens_d_table.tex`, from which `tab:cohens_d` is
a hand-condensed suite-mean summary — the paper table is not emitted directly
by any script.

## Naming traps

**`cot_reasoning_extended.py` writes `cot_vs_baseline.tex`,** while the paper
file is `cot_vs_baseline_extended.tex`. Same content; the name also collides
with what `analysis/cot_reasoning.py` writes into a different directory. Check
the directory, not the filename.

**Five of the 13 were hand-edited** from `\begin{table}` to `\begin{table*}`
so they span both columns. Content is untouched, so a regenerated file differs
from the paper copy only in that one token.

## Superseded modules, kept on purpose

These produce nothing the camera-ready uses, but are reachable from committed
`scripts/rebuttal/*.sh` — the provenance record for the appendix numbers.
Deleting them would leave those scripts broken, which is worse than carrying
unused code.

| Module | Superseded by | Still referenced from |
|---|---|---|
| `analysis/intensity.py` | `intensity_pathway.py` | `_wrap_up_p2p5.sh` |
| `analysis/api_cost_estimate.py` | — (cost projection, never a paper artifact) | `api_smoke_large.sh` |
| `analysis/cot_reasoning.py` | `cot_reasoning_extended.py` | `_b1_*.sh` |
| `analysis/medical_pilot.py` | `extension_pilot.py` | `_c1_one_model.sh` |


## Two tables that cannot be regenerated

`tab:tool_plaintext` and `tab:history_matched` need input directories that
were never preserved; `tables_appendix.py` emits `---` and a single row
without them. Recorded as D5 in [RECONCILIATION.md](RECONCILIATION.md).

Both were re-run independently on 2026-08-05
(`bash scripts/run_stage3_reruns.sh`). The re-run tables and a
published-vs-re-run comparison are in
`../COLM_camera_ready/addendum/ADDENDUM.md`; the published values stand.
