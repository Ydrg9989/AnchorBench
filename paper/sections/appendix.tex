\paragraph{Dataset.}
The benchmark is generated by
\texttt{poc\_dataset/generate\_poc\_dataset.py} (v0.1, 60 items)
and extended by
\texttt{poc\_dataset/extend\_poc\_dataset\_v0\_2.py} (v0.2, 108 items).
The v0.2 dataset is stored at
\texttt{poc\_dataset/poc\_v0.2.jsonl}.

\paragraph{Inference.}
Open-weight models are run via
\texttt{runner/run\_hf.py} (HuggingFace Transformers, bfloat16,
\texttt{device\_map=auto}).
API models are run via
\texttt{runner/run\_openrouter.py} (OpenRouter).

\paragraph{Mitigations.}
Mitigation experiments use
\texttt{mitigation/run\_mitigation\_hf.py} (local),
\texttt{mitigation/run\_mitigation\_async.py} (API), and
\texttt{mitigation/run\_aalc.py} (AALC).

\paragraph{Evaluation.}
Metrics are computed by
\texttt{mitigation/eval\_mitigations.py} and
\texttt{mitigation/generate\_results.py}.

\paragraph{Configuration.}
Inference settings: temperature~$=0.7$, top-$p=1.0$,
max\_tokens~$=8$ (128 for B3), $n=5$ samples per item.
AALC tested at $\alpha \in \{0.5, 1.0, 1.5\}$.
All configs are stored in \texttt{mitigation/config.yaml}
and \texttt{runner/config.models.yaml}.

\paragraph{Stress tests.}
Generated by \texttt{mitigation/generate\_stress.py};
stored at \texttt{poc\_dataset/stress\_test.jsonl}.
