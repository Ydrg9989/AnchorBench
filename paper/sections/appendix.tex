\paragraph{Dataset.}
The benchmark is generated by the pipeline in
\texttt{src/anchorbench\_v1/} and stored as JSONL files
(one for \textsc{ItemSpecs}, one for \textsc{PromptViews}).
Five pilot datasets are used in the reported experiments:
\begin{itemize}
\item \textbf{External pilot:} 90~items $\times$ 5~conditions
  $=$ 450~prompts (15 per domain, 6~domains).
\item \textbf{History pilot:} 60~items $\times$ 5~conditions
  $=$ 300~prompts (10 per domain, 6~domains), with each
  non-control condition requiring two inference stages.
\item \textbf{ICL pilot:} 180~items $\times$ 5~conditions
  $=$ 900~prompts (30 per domain, 6~domains), with three
  few-shot demonstrations per item.
\item \textbf{RAG pilot:} 180~items $\times$ 5~conditions
  $=$ 900~prompts (30 per domain, 6~domains), with a frozen
  three-document corpus per item.
\item \textbf{Tool pilot:} 180~items $\times$ 5~conditions
  $=$ 900~prompts (30 per domain, 6~domains), with structured
  tool outputs rendered via each model's chat template.
\end{itemize}
All generation is fully deterministic (seed $= 42$).

\paragraph{Inference.}
Open-weight models are served via HuggingFace Transformers
(bfloat16, \texttt{device\_map=auto}) on NVIDIA H100 GPUs
(95\,GB VRAM).
All experiments use greedy decoding (temperature $= 0.0$,
seed $= 42$, max tokens $= 512$).
The History suite's two-stage inference uses the tokenizer's
\texttt{apply\_chat\_template} to construct multi-turn
conversations with the model's own Stage~1 response as an
assistant turn.
The Tool suite renders prompts through each model's native
tool-calling chat template with \texttt{role:~"tool"} messages.
The ICL suite uses plaintext prompts with three few-shot
demonstrations; no chat template or tool messages are required.

\paragraph{Evaluation.}
Each suite has a dedicated evaluation script
(\texttt{scripts/eval/run\_\{suite\}\_v2.py}) that loads the
corresponding pilot dataset, runs inference, applies the
two-stage parsing pipeline (regex $\to$ LLM fallback via
Qwen2.5-1.5B-Instruct), and computes the unified metrics
(UAI, TAR, Disc$_{\Delta}$, MAE, Acc$_{10}$, parse rate).
The History-suite script additionally orchestrates two-stage
inference and computes ACR and RR.
All evaluation scripts share a common metrics module
(\texttt{scripts/eval/unified\_metrics.py}).

\paragraph{Hardware.}
All experiments run on a server with 4$\times$ NVIDIA H100
GPUs (95\,GB VRAM each).
Four models are evaluated in parallel (one per GPU).
The external pilot completes in under 30~minutes per model;
the history pilot in 1--21~minutes depending on model size.
The ICL, RAG, and tool pilots use batched inference
(batch size~$= 32$) and complete in under 15~minutes per
model.
