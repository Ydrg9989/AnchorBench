The experimental setup for all five pilots (external, history,
ICL, RAG, and tool) is described in \S\ref{sec:pilot-setup}.
This section provides additional details on infrastructure
and reproducibility.

\paragraph{Inference.}
Open-weight models are served via HuggingFace Transformers
(bfloat16, \texttt{device\_map=auto}) on NVIDIA H100 GPUs
(95\,GB VRAM).
All experiments use greedy decoding (temperature $= 0.0$)
with max tokens $= 512$ and a fixed random seed (42).
For the History suite's two-stage conditions, Stage~1 and
Stage~2 are executed sequentially within a single conversation
using the tokenizer's chat template.
For the Tool suite, prompts are rendered through each model's
native tool-calling chat template, with \texttt{role:~"tool"}
messages conveying structured JSON tool outputs.
For the ICL suite, prompts are plaintext with three few-shot
demonstrations; no chat template or tool messages are required.

\paragraph{Parsing pipeline.}
We employ a two-stage parsing pipeline:
(1)~a regular expression extracts the last standalone integer
in $[0, 100]$ from the response;
(2)~if the regex fails, an LLM fallback
(Qwen2.5-1.5B-Instruct) extracts the final numeric answer.
All models achieve $\geq$98\% parse rate on the external,
history, ICL, and RAG pilots (the ICL pilot achieves 100\%
across all four models).
On the tool pilot, Qwen models maintain $\geq$98\% parse
rates, while Llama models achieve 79--86\%, reflecting the
additional formatting challenge of structured tool-calling
context.

\paragraph{Parallelism.}
With four available H100 GPUs, all four models are evaluated
in parallel (one model per GPU).
The external pilot (450~prompts per model) completes in under
30~minutes per model; the history pilot (300~prompts, with
two-stage inference for 240 of them) completes in
approximately 1--21~minutes per model, depending on model size.
The ICL, RAG, and tool pilots use batched inference
(batch size~$= 32$) for improved GPU utilization;
900~prompts per model complete in under 15~minutes per model.
